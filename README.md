# Toolbox v3 wireframes

Clickable wireframes for Toolbox v3, a toolbox for Travian: Legends players. Served at https://toolbox.ondrejstarek.cz.

Everything here is illustrative: player, alliance and village names, coordinates and population come from the public daily map data of ts12.x1.europe; troop counts, sitters, Discord tags, roles and scan ages are made up. Not affiliated with Travian Games. The unit and bounty icons are the game's own artwork.
